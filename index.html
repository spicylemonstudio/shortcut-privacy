숏컷 / 개인정보처리방침

시행일: 2026년 10월 16일 · 개발자: SpicyLemon

숏컷(이하 "앱")은 SpicyLemon이 만든 안드로이드 앱으로, 인스타그램 릴스, 유튜브 쇼츠, 네이버 클립, 카카오톡 "지금" 탭의 숏폼 화면을 막거나 이용 시간을 제한합니다. 이 방침은 앱이 어떤 정보를 다루고, 어떻게 쓰며, 무엇을 하지 않는지 설명합니다.

1. 접근성 서비스(AccessibilityService) 사용

앱은 인스타그램 릴스, 유튜브 쇼츠, 네이버 클립, 카카오톡 "지금" 탭의 숏폼 화면을 알아채기 위해 안드로이드 접근성 서비스를 사용합니다.

  • 확인하는 것: 인스타그램·유튜브·네이버·카카오톡 앱이 열려 있을 때, 현재 화면에 숏폼(릴스·쇼츠·클립 등) 재생 화면이 있는지 여부만 확인합니다. 그 밖의 앱 화면은 확인하지 않습니다.
  • 하는 일: 숏폼 화면이면 사용자가 고른 설정에 따라 뒤로가기 또는 홈 화면으로 이동시키고, 숏폼 화면에 머문 시간을 기록합니다. 카카오톡은 뒤로가기를 하면 앱이 꺼지므로, 대신 카카오톡 하단의 "지금" 탭 버튼을 눌러 오픈채팅 화면으로 돌려보냅니다. 화면을 직접 터치하는 동작(제스처)은 하지 않습니다.
  • 하지 않는 것: 화면에 표시되는 영상, 글, 메시지, 계정 정보 등의 내용을 읽거나 저장하지 않습니다.

접근성 서비스는 사용자가 앱 안의 안내를 확인하고 동의한 뒤, 기기 설정에서 직접 켤 때만 작동합니다. 언제든 기기 설정 → 접근성에서 끌 수 있습니다.

2. 앱 사용 시간 읽기 (선택)

사용자가 "사용 정보 접근"을 허용한 경우에만, 기기의 앱 사용 기록(설정의 앱별 사용 시간과 같은 데이터)에서 인스타그램·유튜브·네이버·카카오톡 앱의 사용 시간만 읽습니다. 최근 하루 평균과, 이 네 앱의 사용 시간 중 숏폼(릴스·쇼츠·클립 등)이 차지하는 비중을 보여주는 데 씁니다. 다른 앱의 사용 기록은 사용하지 않으며, 허용하지 않아도 차단 기능은 그대로 동작합니다. 기기 설정에서 언제든 끌 수 있습니다.

3. 기기에 저장하는 정보

  • 날짜별·앱별(인스타그램·유튜브·네이버·카카오톡) 숏폼 화면 이용 시간
  • 날짜별 인스타그램·유튜브·네이버·카카오톡 앱 전체 사용 시간 (사용 정보 접근을 허용한 경우)
  • 앱 설정(차단 모드, 하루 한도, 연속 시청 한도 등)

이 정보는 사용자의 기기 안에만 저장되며, 이용 시간 기록은 60일이 지나면 자동으로 삭제됩니다. 앱을 삭제하면 모두 지워집니다.

4. 수집·전송·공유하지 않는 정보

앱은 개인정보를 수집하지 않으며, 기기 밖의 서버나 제3자에게 사용자 정보를 보내거나 공유하지 않습니다. 광고, 분석 도구, 계정 가입 기능이 없습니다.

앱의 일부 버전은 새 버전이 있는지 확인하기 위해 공개된 버전 정보 파일을 내려받을 수 있습니다. 이때도 사용자에 관한 정보는 보내지 않습니다.

5. 아동

앱은 만 13세 미만 아동을 대상으로 하지 않습니다.

6. 방침 변경

방침이 바뀌면 이 페이지에 게시하고 시행일을 갱신합니다.

ShortCut — Privacy Policy

Effective: October 16, 2026 · Developer: SpicyLemon

ShortCut is an Android app that blocks or time-limits short-form video screens: Instagram Reels, YouTube Shorts, Naver Clip, and KakaoTalk short-form (in the "Now" (지금) tab).

  • Accessibility Service: While Instagram, YouTube, Naver, or KakaoTalk is open, the app only checks whether a short-form player screen (Reels, Shorts, Clip, etc.) is currently shown. If so, it performs a Back or Home action according to the user's settings and records the time spent on short-form screens. For KakaoTalk, Back would close the app, so instead the app presses KakaoTalk's bottom "Now" (지금) tab button to return to the Open Chat view. The app does not perform screen-touch gestures. It does not read or store on-screen content such as videos, text, messages, or account information, and it does not inspect other apps. The service works only after the user reads the in-app disclosure, consents, and turns it on in system settings; it can be turned off at any time.
  • App usage time (optional): Only if the user grants Usage Access, the app reads the usage time of the Instagram, YouTube, Naver, and KakaoTalk apps from the device usage history (the same data as the per-app screen time in system settings) to show the recent daily average and the share of short-form content within these four apps' total time. Other apps' usage is not used. Blocking works without it, and it can be revoked in system settings.
  • Stored on device only: daily per-app short-form usage time, daily total Instagram/YouTube/Naver/KakaoTalk usage time (if Usage Access is granted) (deleted after 60 days) and app settings. Everything is removed when the app is uninstalled.
  • No collection or sharing: The app does not collect personal data and does not send or share user data with any server or third party. No ads, analytics, or accounts. Some versions may download a public version-info file to check for updates; no user data is sent.
  • Children: The app is not directed to children under 13.
