숏컷 / 개인정보처리방침

시행일: 2026년 10월 15일 · 개발자: SpicyLemon

숏컷(이하 "앱")은 SpicyLemon이 만든 안드로이드 앱으로, 인스타그램 릴스와 유튜브 숏츠 화면을 막거나 이용 시간을 제한합니다. 이 방침은 앱이 어떤 정보를 다루고, 어떻게 쓰며, 무엇을 하지 않는지 설명합니다.

1. 접근성 서비스(AccessibilityService) 사용

앱은 릴스·숏츠 화면을 알아채기 위해 안드로이드 접근성 서비스를 사용합니다.

  • 확인하는 것: 인스타그램·유튜브 앱이 열려 있을 때, 현재 화면에 릴스·숏츠 재생 화면이 있는지 여부만 확인합니다. 그 밖의 앱 화면은 확인하지 않습니다.
  • 하는 일: 릴스·숏츠 화면이면 사용자가 고른 설정에 따라 뒤로가기 또는 홈 화면으로 이동시키고, 숏폼 화면에 머문 시간을 기록합니다.
  • 하지 않는 것: 화면에 표시되는 영상, 글, 메시지, 계정 정보 등의 내용을 읽거나 저장하지 않습니다.

접근성 서비스는 사용자가 앱 안의 안내를 확인하고 동의한 뒤, 기기 설정에서 직접 켤 때만 작동합니다. 언제든 기기 설정 → 접근성에서 끌 수 있습니다.

2. 기기에 저장하는 정보

  • 날짜별·앱별(인스타그램·유튜브) 숏폼 화면 이용 시간
  • 앱 설정(차단 모드, 하루 한도, 연속 시청 한도 등)

이 정보는 사용자의 기기 안에만 저장되며, 이용 시간 기록은 60일이 지나면 자동으로 삭제됩니다. 앱을 삭제하면 모두 지워집니다.

3. 수집·전송·공유하지 않는 정보

앱은 개인정보를 수집하지 않으며, 기기 밖의 서버나 제3자에게 사용자 정보를 보내거나 공유하지 않습니다. 광고, 분석 도구, 계정 가입 기능이 없습니다.

앱의 일부 버전은 새 버전이 있는지 확인하기 위해 공개된 버전 정보 파일을 내려받을 수 있습니다. 이때도 사용자에 관한 정보는 보내지 않습니다.

4. 아동

앱은 만 13세 미만 아동을 대상으로 하지 않습니다.

5. 방침 변경

방침이 바뀌면 이 페이지에 게시하고 시행일을 갱신합니다.

ShortCut — Privacy Policy

Effective: October 15, 2026 · Developer: SpicyLemon

ShortCut is an Android app that blocks or time-limits Instagram Reels and YouTube Shorts screens.

  • Accessibility Service: While Instagram or YouTube is open, the app only checks whether a Reels/Shorts player screen is currently shown. If so, it performs a Back or Home action according to the user's settings and records the time spent on short-form screens. It does not read or store on-screen content such as videos, text, messages, or account information, and it does not inspect other apps. The service works only after the user reads the in-app disclosure, consents, and turns it on in system settings; it can be turned off at any time.
  • Stored on device only: daily per-app short-form usage time (deleted after 60 days) and app settings. Everything is removed when the app is uninstalled.
  • No collection or sharing: The app does not collect personal data and does not send or share user data with any server or third party. No ads, analytics, or accounts. Some versions may download a public version-info file to check for updates; no user data is sent.
  • Children: The app is not directed to children under 13.
